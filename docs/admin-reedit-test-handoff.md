# 重新編輯測試模式交付狀態

本分支從 d1484cc 建立。正式資料庫無 Migration。SQLite 測試資料只在臨時目錄建立。

## 憑證核對

店主使用平常的 Passkey 重新登入。登入安全頁會在實際通過 WebAuthn 驗證的註冊紀錄標示「本次登入驗證的憑證」並顯示 SHA-256 指紋。請核對建立時間、最後使用時間及完整指紋。名稱相同的其他憑證有不同指紋。同步同一筆 Passkey 的裝置共用這個身分。店主另外確認後，才可將完整指紋加入 ADMIN_REEDIT_TEST_CREDENTIAL_SHA256。現階段名單保持空白。

## 停用與回退

ADMIN_REEDIT_TEST_ENABLED 未設定或不等於 true 時，服務端授權檢查拒絕存取。隔離交接儲存每次使用都必須呼叫線上授權回查，連線故障應拒絕。正在進行中的請求在寫入或派工前必須再次確認。重新啟用以前須使舊交接與工作階段永久失效。現階段完成的是元件演練。

部署後的回退順序：先關閉測試開關、停用隔離入口與所有寫入處理程序、撤銷隔離工作階段，再將正式服務回退至該次部署前記錄的成功 Railway deployment ID。保留正常客戶送印服務。此分支不需要回填或回滾正式訂單。

## 尚未達到部署條件

正式唯讀快照、跨站單次交接端點、隔離端每項操作的線上回查、七天清除、正式列表入口、完整站點停用與回滾演練都須在整合完成後驗證。只有元件測試通過時不得啟用。
